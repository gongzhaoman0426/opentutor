# 章节内容编辑工作台

更新时间：2026-10-11

## 作者的操作路径

主页创建项目 → 按章节写 Markdown、引用图片 → 配置当前章节 → 生成本章视频 → 预览 → 下载本章视频。

创建项目只需名称。编辑页左侧为可收起的章节目录，中间为当前章节的 Markdown 编辑器，右侧为“Markdown / 视频”预览切换。顶部保留保存状态、生成视频和下载视频。面板内部滚动，整个制作页保持单屏；窄屏切换编辑和预览，避免挤压三列。

项目设置与生成管线不再成为必须完成的表单和阶段导航。素材、任务、诊断和可选配置按需打开。

主页和编辑器顶栏提供「中文 / English」界面语言切换，默认中文，以浏览器 cookie 记住选择，刷新和页面跳转后保留。控件、弹窗、状态、版本时间、语言／音色名称和组件库说明同步切换。切换立即生效，不重载页面，不改写草稿、项目修订、视频生成语言或音色，也不重置播放进度。已有文稿、标题、生成视频、组件示例的画面内容和原始服务诊断保留源语言；新建空章节与无标题导入的默认名称按当时的界面语言创建。

## 每章一个视频与生成配置

顶部“生成视频”打开当前章节的配置面板。面板包含 720p/1080p、视频语言、微软免费音色与试听、语速、四种预设风格、一句话风格描述、Codex 模型下拉以及稳定／创作模式。先选择视频语言，再从对应语言的音色中选择；语言以微软实际目录为准，生成的标题、画面文字、旁白和字幕使用所选语言，原始引用图片与代码标识保留。可只保存设置，也可保存后生成本章；两种操作都会把整套参数（包括语言和音色）记为本项目最新默认值，后续未配置、新建和导入的章节自动沿用。前序章节、已有视频、进行中的任务和独立设置保留原参数，刷新页面后继承关系仍然有效。

视频用途默认“自动判断”，可选择知识讲解、产品介绍、信息汇报或故事叙述。自由填写的“创作要求”表达用途、结构、语气和节奏，也可以描述预设列表之外的视频类型；目标受众默认普通观众。用途预设不会改变编辑流程，也不限定生成能力。配色与视觉风格使用单独的“风格描述”。

风格描述进入 AI 编排，生成的五色调色板实际用于画面；模板提供默认调色板，并检查文字对比度。稳定模式在输出 schema 和运行校验两层限制为预设对象；创作模式允许大量使用 JavaScript 动态 SVG 组件，同时仍可使用预设组件和原始图片。

组件库按需打开，预览所有现有对象类型与布局，播放与最终视频共用同一个渲染器。自定义组件示例包括波形、圆周运动和动态柱状图。

右侧视频始终属于选中章节。每章独立保存生成参数、预览及成片；修改其他章节、排序或完成其他章节的视频不会使本章成片失效。修改本章内容、标题、设置或实际引用的素材会标记本章预览为旧版本，继续允许查看。

视频区提供“视频版本”选择器及生成时间。版本号按本章成功生成的完整可播放视频从 1 连续编号；自动保存、设置变更、失败、取消、增量预览、仅编排和纯导出都不增加视频版本。项目 `revision` 是保存与并发控制使用的文稿修订号，不作为视频次数展示。

选择历史版本只切换播放器，不回滚当前 Markdown 或设置；使用该次生成冻结的画面、完整配音、素材与尺寸。新任务运行和轮询时保持作者选中的旧版，也可以切回“最新／生成中”查看进度。换章或换版本时暂停播放并丢弃迟到响应，避免串片。

旧项目读取时补齐新参数默认值，保留已有受众与其他选项，不写回历史输入，也不因此使旧视频过期。修改视频用途或创作要求属于本章输入变化。

## 文稿与图片

每章拥有稳定 ID、可修改标题和 Markdown。章节可以新增、删除、排序；导入文件按 Markdown 标题结构拆章，不拆分代码围栏中的 `#`。旧项目先适配为可编辑章节，打开页面本身不产生新版本。

图片可上传、粘贴或拖入，成功后在编辑位置插入 `![说明](asset://UUID)`。素材列表支持重复插入。Markdown 预览使用同一注册素材映射，支持行内与引用式图片；缺失素材显示可理解的提示。

自动保存采用带版本号的请求。请求发出后继续输入，返回结果不能覆盖新的文字；并发冲突保留本地草稿，并明确提示。点击生成前等待所需保存完成，然后冻结输入快照。

## 生成与下载

| 操作 | 后台工作 | 用户得到的结果 |
| --- | --- | --- |
| 生成本章视频（`preview` + `chapterId`） | 解析当前章、识别引用图片、参考全项目关系、编排本章、校验、微软配音、连续音轨、字幕与时间轴 | 本章可交互播放的完整预览，不生成 MP4 |
| 下载视频（`export`） | 对作者当前选中的完整视频版本执行 Remotion 编码 | 同版已有有效 MP4 直接下载；历史版本没有成片时按其冻结输入渲染，不要求先更新当前文稿 |

任务运行时编辑器仍可使用。已有视频保持可播放，新任务按完成进度提供场景和配音。估算片段、旧版本与当前完整预览分别标记，不能把缺少音频的预览导出为正式视频。

取消或失败保留可用的旧结果。本章输入变化后的旧任务结果进入历史候选；只有其他章节变化时，可发布当前章结果而不覆盖文稿。旧整项目生成接口与产物保留兼容。

历史导出与当前生成分别跟踪，互不覆盖最新预览指针；下载完成不创建新视频版本。历史编号从已有成功任务的最终结果恢复，不从项目保存次数推算。缺少完整生成记录的旧快照保留预览能力，不伪造版本号。

## 图片参与表达

AI 实际接收图片像素。图片分析记录可见文字、类型、概述、不确定项和可识别区域；章节编排同时读取正文、图片说明、前后关系与全项目规划。

画面以保留比例的原图显示为默认。对已识别区域可安排局部聚焦和高亮；没有足够定位依据或坐标无效时回退完整原图。每个图片引用必须被对应来源的场景采用，并在讲稿期间显示。这个检查保证图片被安排使用，不能证明所有视觉解读和内容事实都正确。

## 连续播放

完整配音使用一条连续音轨，画面和字幕按照同一时间轴切换。仅修剪独立 TTS 片段首尾多余静音，保留句内自然停顿，不人为为每段和换页增加空白。

播放器的输入配置保持稳定，进度更新不能每帧重建播放配置或重置时钟。文本和公式缓存，加载不足时画面与音频共同等待。画面修改可沿用有效音轨，讲稿、音色、语速、顺序和时长变化使对应音轨失效。
