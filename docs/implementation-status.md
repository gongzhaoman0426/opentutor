主流程为“创建项目 → 按章节写 Markdown/引用图片 → 生成视频 → 预览 → 下载”。生成时无需逐阶段操作，也无需预先渲染 MP4。图片实际像素进入 Codex，逐次检查来源图片是否安排在对应讲解中显示；模糊或无法确认的局部区域回退全图。生成中可看增量结果或旧视频，未配音片段明确标记。详细层级见[工作台设计](./workbench-design.md)。

用途默认自动判断；用途预设是编排起点，不限制适用类型，自由创作要求可补充其他表达形式、语气、节奏和重点。导演、全项目概览、图片分析、分批生成、修复和单场景重生成均使用这些信息，非教学内容不强加课堂结构。

生成前打开本章设置，保存后只生成本章。风格描述产生实际画面配色；模型选择应用于视觉分析、全项目关系、分镜与修复。参数、源内容与引用素材绑定章节预览和下载，不能误用其他章节的成片。

旧项目、历史版本和任务快照读取时补齐新参数默认值，保留原受众；auto／空创作要求维持旧章节指纹。旧项目读取不会自动改写文稿或使旧视频失效；保存章节修改后才切换来源模式。完整配音继续采用连续整轨，稳定播放器配置防止控制栏更新导致音频自动回跳。
